# ✅ React To-Do List
 
A clean, minimal To-Do List app built with React — featuring task management and drag-free reordering.
 
---
 
## 🚀 Features
 
- Add new tasks
- Remove tasks
- Move tasks **up** or **down** in the list
- Clean dark UI
- Built with pure React — no external libraries
---
 
## 🛠️ Built With
 
- React (useState)
- HTML & CSS
- JavaScript (ES6+)
---
 
## 💡 What I Learned
 
- Managing arrays in React state correctly
- Using destructuring swap to reorder items:
```js
[tasks[i], tasks[i - 1]] = [tasks[i - 1], tasks[i]];
```
- Keeping components clean and readable
